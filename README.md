# PORT010

Leer- en praktijkplatform voor PORT op Melanchthon Mavo Schiebroek. Docenten maken en publiceren projecten,
leerlingen werken ze stap voor stap door, externe opdrachtgevers melden projecten aan.

**Fase 1 (demo):** alle omgevingen werken met fictieve gegevens die in de eigen browser worden bewaard.
Kies bovenaan bij "Bekijk als" welke omgeving je ziet. Er is nog geen inlog en geen database.

Lokaal draaien: `npm install` en `npm run dev`. Elke push naar `main` zet de site online via GitHub Pages.
